Classification: Definition
l Given a collection of records (training set )
– Each record is by characterized by a tuple 
(x,y), where x is the attribute set and y is the 
class label
x: attribute, predictor, independent variable, input
y: class, response, dependent variable, output
l Task:
– Learn a model that maps each attribute set x 
into one of the predefined class labels y

---------- страница 48 ----------
Problem with large number of partitions
Test conditions that result in a large number of outcomes 
may not be desirable, because the number of records 
associated with each partition is too small to enable us to 
make any reliable predictions.
Two strategies:
Restrict the test conditions to binary splits only (used in 
CART)
Modify the splitting criterion to take into account the 
number of outcomes produced by the attribute test 
condition – an example of a criterion known as gain ratio
used in C4.5 decision tree algorithm is presented on the 
next slide.

---------- страница 49 ----------
Gain Ratio
l
Gain Ratio: 
Parent Node, pis split into kpartitions (children)
niis number of records in child node i
– Adjusts Information Gain by the entropy of the partitioning 
(SplitInfo).

---------- страница 56 ----------
Decision Tree Based Classification
l Advantages:
Relatively inexpensive to construct
Extremely fast at classifying unknown records (the tree is built)
Easy to interpret for small-sized trees
Robust to noise (especially when methods to avoid overfitting are 
employed)
Can easily handle redundant attributes
Can easily handle irrelevant attributes (unless the attributes are 
interacting)
An attribute is redundant if it is strongly correlated with another attribute in 
the data. One of the two redundant attributes will not be used for splitting 
once the other attribute has been chosen. But if there are many irrelevant 
attributes (not useful for classification) some may be chosen and it will 
unnecessarily create larger tree. 

---------- страница 57 ----------
Decision Tree Based Classification
l Disadvantages: .
Due to the greedy nature of splitting criterion,  interacting attributes (that 
can distinguish between classes together but not individually) may be 
passed over in favor of other attributed that are less discriminating.
Each decision boundary involves only a single attribute.
