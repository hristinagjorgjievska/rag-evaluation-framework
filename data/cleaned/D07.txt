Types of Attributes 
There are different types of attributes
Categorical data represents characteristics( person’s gender, 
language etc). Categorical data can also take on numerical 
values, though they represent some ordering. There are two 
types of categorical data
– Nominal can be expressed in words or in numbers, but can 
not be ordered in some meaningful way  and we can not 
perform arithmetic operations on them (ID numbers, eye 
color, zip codes)
– Ordinal data can be ranked in a natural order (rankings 
(e.g., user rates from 1-10), grades, height {tall, medium, 
short}

---------- страница 10 ----------
Numerical data is used to express quantitative values and we can 
transform this data with arithmetic operations. It can be discrete and 
continuous. Continuous data is additionally explained as
– Interval data - numeric values that are ordered and where we 
know the exact differences between the values, but there is no 
“true zero” (calendar dates, temperatures in Celsius or 
Fahrenheit.) Some statistics can not be applied.
– Ratio values also ordered units that have the same difference. 
Ratio values are the same as interval values, with the 
difference that they do have an absolute zero. Good 
examples are height, weight, length, temperature in Kelvin, 
length, counts, elapsed time (e.g., time to run a race) etc.

Discrete and Continuous Attributes 
Discrete Attribute
– Has only a finite or countably infinite set of values
– Examples: zip codes, counts, or the set of words in a 
collection of documents 
– Often represented as integer variables.   
– Note: binary attributes are a special case of discrete 
attributes 
Continuous Attribute 
– Has real numbers as attribute values
– Examples: temperature, height, or weight.  
– Practically, real values can only be measured and 
represented using a finite number of digits.
– Continuous attributes are typically represented as floating-
point variables.

(example male vs female). On the contrary, in asymmetric

---------- страница 18 ----------
Key Messages for Attribute Types
The types of operations you choose should be 
“meaningful” for the type of data you have
– Distinctness, order, meaningful intervals, and meaningful 
ratios are only four (among many possible) properties of 
data
– The data type you see – often numbers or strings – may not 
capture all the properties or may suggest properties that are 
not present
– Analysis may depend on these other properties of the data
Many statistical analyses depend only on the distribution
– In the end, what is meaningful can be specific to domain

How to deal with outliers
We should distinguish noise from outliers. Noise is
random error or variance in the data (mistake, mislabel
etc.) Outlier is part of the data, just significantly different
compared to the rest.
It does affect statistical results so we may need to drop it.
But it may also change our assumption of the data.
Sometimes we have to analyze the domain in details
before we decide to omit it.
Different techniques: IQR for numeric outliers, Residual
analysis in Linear regression, Mahalanobis distance, z-
scores etc.

Similarity measure
– Numerical measure of how alike two data objects are.
– Is higher when objects are more alike.
– Often falls in the range [0,1]
Dissimilarity measure
– Numerical measure of how different two data objects are 
– Lower when objects are more alike
– Minimum dissimilarity is often 0
– Upper limit varies
Proximity refers to a similarity or dissimilarity
Check the range of the measure, before using an algorithm.

Common Properties of a Distance
Distances, such as the Euclidean distance, 
have some well known properties.
d(x, y) 0   for all x and y and d(x, y) = 0 if and only 
if  x = y.
d(x, y) = d(y, x)   for all x and y. (Symmetry)
d(x, z) d(x, y) + d(y, z)
for all points x, y, and z.  
(Triangle Inequality)
where d(x, y) is the distance (dissimilarity) between 
points (data objects), x and y.
A distance that satisfies these properties is a 
metric

Similarities, also have some well known

s(x, y) = 1 (or maximum similarity) only if x = y.

s(x, y) = s(y, x)

Similarity Between Binary Vectors
Common situation is that objects, x and y, have only binary 
attributes
Compute similarities using the following quantities
f01 = the number of attributes where x was 0 and y was 1
f10 = the number of attributes where x was 1 and y was 0
f00 = the number of attributes where x was 0 and y was 0
f11 = the number of attributes where x was 1 and y was 1
Simple Matching coefficient and Jaccard coefficient
SMC =  number of matches / number of attributes 
=  (f11 + f00) / (f01 + f10 + f11 + f00)
J = number of 11 matches / number of non-zero attributes
= (f11) / (f01 + f10 + f11)          often defined as J = |A∩B|
|A∪B|

---------- страница 65 ----------
Remarks on Pearson Correlation
The previous definition of correlation corresponds to the so
called Pearson correlation coefficient and it is used for interval
od ratio data.
The variables should ideally be jointly normally distributed and
have equal variances and if we have small sample which does
not fulfil this criteria there might be a problem with the
estimated value. But it is also important that the data are
continuous, paired and the scatterplot shows some linear
relationship. The measure is also sensitive to outliers.

Information and Probability
Information relates to possible outcomes of an event 
– transmission of a message, flip of a coin, or measurement 
of a piece of data 
The more certain an outcome, the less information 
that it contains and vice-versa
– For example, if a coin has two heads, then an outcome of 
heads provides no information
– More quantitatively, the information is related the 
probability of an outcome
The smaller the probability of an outcome, the more information it 
provides and vice-versa
– Entropy is the commonly used measure of uncertainty.
