y: class, response, dependent variable, output
l Task:
– Learn a model that maps each attribute set x

may not be desirable, because the number of records 
associated with each partition is too small to enable us to 
make any reliable predictions.

CART)


number of outcomes produced by the attribute test

Decision Tree Based Classification
l Advantages:
–
Relatively inexpensive to construct
–
Extremely fast at classifying unknown records (the tree is built)
–
Easy to interpret for small-sized trees
–
Robust to noise (especially when methods to avoid overfitting are 
employed)
–
Can easily handle redundant attributes
–
Can easily handle irrelevant attributes (unless the attributes are 
interacting)
An attribute is redundant if it is strongly correlated with another attribute in 
the data. One of the two redundant attributes will not be used for splitting 
once the other attribute has been chosen. But if there are many irrelevant 
attributes (not useful for classification) some may be chosen and it will 
unnecessarily create larger tree.
