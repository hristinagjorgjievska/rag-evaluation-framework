# RAG Evaluation Framework

---

## Македонски

Систематска евалуација на различни конфигурации на Retrieval-Augmented Generation (RAG) системи врз корпус од документи од областа на податочното рударење и машинското учење.

### Истражувачко прашање

Како различни поставки на RAG систем влијаат врз точноста на одговорите, точноста на цитирањето и способноста системот да каже „не можам да одговорам од дадените документи“ кога одговорот не постои во корпусот?

---

## English

Systematic evaluation of Retrieval-Augmented Generation (RAG) configurations on a curated corpus of data mining and machine learning documents.

### Research question

How do different RAG configurations affect answer accuracy, citation correctness, and the system's ability to say "I cannot answer from the given documents" when the answer is not in the corpus?
